Close the state-cleanup-on-disruption gap cluster (UAT tests 6, 16, 20). The user's overarching principle: whenever something stops the audio or the device state changes adversely, Jay-6 must unlatch + clear ALL pad highlights + release notes — never leave a stuck-on UI or a hanging MIDI note.

Three concrete failures observed:
1. Mode-switch / panic / device-disconnect stop the audio but leave pads lit + latch state set (tests 16, 20).
2. In Ext mode, disconnecting the input device leaves Ext selected with no input — had to manually switch to Int (test 20 hot-plug).
3. Browser reload while a latched chord sounds leaves the note hanging on the synth (test 6) — WebMidi tears down without firing note-offs.

Purpose: a single, reliable clear-all path wired to every disruption source, plus an Ext→Int fallback, plus an unload-time panic.
Output: host.panic() drives full cleanup (audio + latch + highlights), App.svelte clears the latched-highlight state on panic, falls back to Int when the input vanishes, and panics on pagehide/beforeunload.
