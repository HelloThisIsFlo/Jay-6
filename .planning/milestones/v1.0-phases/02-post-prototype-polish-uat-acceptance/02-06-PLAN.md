<objective>
Close the two MIDI-monitor-evidenced transport-sync gaps (UAT tests 11 + 16): rhythm-phase alignment under Ext clock and OP-1 transport semantics. Also close the test-16 Int-switch state-leak gap (engines kept following OP-1 tempo after switching to Int), since both live on the same tickSource Ext/Int `setMode` boundary.

Root causes (already located in the UAT, hard MIDI-monitor evidence attached):
1. **Phase misalignment** — all three time-driven engines arm against a LOCAL tick counter that starts at 0 on pad-press (`armUntilTick = nextDownbeatTick(this.tickCount)`), so the first hit lands one OP-1 quarter after the press (measured +278ms / 0.42-beat off-grid), wherever that falls in OP-1's bar.
2. **Transport semantics** — the OP-1 emits **Continue (0xFB)** on Play, NEVER **Start (0xFA)**. `host.onTransport` keys the arm/reset behavior off `'start'`; `'continue'` sets `armedPosition='resume'`, a stub no engine reads. The intended Play→align behavior never fires from this hardware. Separately, no `TRANSPORT-IN` log appeared even though the bytes were on the wire — listener firing is unconfirmed.
3. **Int-switch leak (transient)** — after switching the clock to Int, Jay-6's rhythm still followed the OP-1's tempo changes (cleared by page reload). `tickSource.setMode()` already calls `detachInputListener()` on a real mode flip, so the leak is either a path where the flip is short-circuited (`if (mode === this.mode) return` guard, or `detachInput` already null while webmidi listeners are still bound) or an engine that retains an external-tick subscription. "Probably already detached" is not verification — we audit the path, harden it, and lock it with a unit test.

Purpose: engines must align to OP-1's ACTUAL bar position, not a beat counted from pad-press; must react to the transport message the OP-1 actually sends; and must go fully deaf to OP-1 timing the moment Int is selected.
Output: an absolute external-tick counter on tickSource, a pure ticks-to-downbeat helper in clock.ts (unit-tested per DEC-tests-data-and-math-only), all three engines arming against it, Continue wired as a valid sync trigger, and a verified-deaf Int-switch path with a regression test.
</objective>
