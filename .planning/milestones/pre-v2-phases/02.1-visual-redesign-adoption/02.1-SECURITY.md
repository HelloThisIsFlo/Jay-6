# Phase 02.1 — Security

> Per-phase security contract for the visual redesign adoption.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser input → Svelte UI | Pointer and keyboard events enter the existing playback bridge. | Local interaction events |
| Web MIDI → TopBar | Browser-provided MIDI status and device names render in setup. | Local device metadata |
| UI controls → application state | Setup and variation controls update existing state and MIDI selectors. | Local UI and routing state |
| State projection → visual semantics | Held and selected state determines active styling. | Local playback state |

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
