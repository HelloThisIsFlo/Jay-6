## Design Token Adoption

| Option | Description | Selected |
|--------|-------------|----------|
| Shared token layer | Extract sketch theme tokens into a small reusable CSS layer, then use scoped Svelte CSS per component. | yes |
| Local component styling | Keep all visual values local to `App.svelte`, `TopBar.svelte`, and `PianoLayout.svelte`. | |
| Heavy design system | Create a broader component/token abstraction. | |

**User's choice:** "Whatever makes more sense" - Flo explicitly deferred to
frontend expertise.

**Notes:** Recommended decision is a small shared token layer plus scoped
component CSS. Avoid a heavy design system or UI library.
