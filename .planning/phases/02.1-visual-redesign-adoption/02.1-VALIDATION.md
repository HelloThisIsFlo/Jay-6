# Phase 02.1 - Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest + svelte-check + Vite build |
| **Config file** | `vite.config.ts`, `tsconfig.json`, `svelte.config.js` |
| **Quick run command** | `just test` |
| **Full suite command** | `just ci` |
| **Estimated runtime** | ~20-60 seconds |

---

## Sampling Rate

- **After every task commit:** Run `just test` when the task changes pure helpers or state mapping; run `just check` when the task changes Svelte/CSS only.
- **After every plan wave:** Run `just ci`.
- **Before `$gsd-verify-work`:** `just ci` must be green.
- **Max feedback latency:** one task commit.
