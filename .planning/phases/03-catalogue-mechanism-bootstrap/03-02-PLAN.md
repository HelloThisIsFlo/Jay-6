## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent-authored JSON to typed domain data | The bundled catalogue is local but changeable; malformed or misleading values must fail before consumers receive them. |
| Public bank index to canonical bank lookup | Numeric caller input crosses into a canonical helper that wraps values unless this module guards first. |
| Validated catalogue to future UI consumer | Phase 4 must receive inert text/domain records without MIDI, state, engine, timing, or mutable canonical-object authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | JSON import and validator in `src/suggestions.ts` | medium | mitigate | Treat the import as `unknown`, enforce exact shape and positive allowlists, validate bounds before lookup, project fresh values, and throw all deterministic diagnostics before exporting catalogue data. |
| T-03-02 | Tampering | Cross-entry identity and sequence checks | medium | mitigate | Run collision-safe duplicate checks only over individually valid records and report both source locations so corrupt duplicates cannot enter the resolved catalogue. |

| T-03-04 | Denial of Service | Import-time validation | low | accept | The source is a bundled local file fixed to three records in this phase; linear scans are bounded and any invalid content intentionally blocks startup/build for repair. |
