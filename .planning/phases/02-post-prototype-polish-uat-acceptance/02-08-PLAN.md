Close two small, independent input-handling gaps surfaced in UAT.

1. **Pad release-edge race (test 4, major — stuck MIDI note).** Press pad, drag the mouse off the pad while still pressed, release: intermittently (when release + pointer-leave fire near-simultaneously) the pad stays lit AND the MIDI note hangs (note-off missed). Audit and guarantee preventDefault on every app-consumed key.

function handlePointerDown(e: PointerEvent, k: Key) {
  const c = chordFor(k); if (!c) return;
  (e.currentTarget as HTMLElement).setPointerCapture(e.pointerId);
  e.preventDefault();
  onPress(k, c.notes);
}
function handlePointerUp(e: PointerEvent, k: Key) {
  (e.currentTarget as HTMLElement).releasePointerCapture?.(e.pointerId);
  e.preventDefault();
  onRelease(k);
}
