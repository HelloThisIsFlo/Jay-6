# Sketch 001: Jay-6 Visual Redesign

## Design Question

Which visual system and component treatments should Jay-6 adopt as an in-between redesign before milestone 2 sequencer work?

## How To View

Open `.planning/sketches/001-jay-6-visual-redesign/index.html`, or serve the repo and open:

`http://127.0.0.1:8765/.planning/sketches/001-jay-6-visual-redesign/index.html`

Original imported copy remains at `.research/design/Jay-6 Redesign (standalone).html`.

## Winner

Imported v3 recommended composition:

- TopBar C2: performance-first bar, routing and BPM folded into one pill, setup popover on tap.
- Pads: lifted bevel treatment, separate J-6 hardware rows, no piano-style overlap.
- Variations: per-style pickers instead of one universal selector.
- Toast: Option A, bottom-center queued pill with countdown.
- Progressions: Option A, chord-chip rail below pads, with collapsed sheet variant for mobile.
- Tokens: dark instrument chrome, cream pads, orange active accent, muted steel system accent.

## Variants Preserved

- TopBar: current, grouped row, two-tier, performance-first C, recommended C2, C2 setup open, iPad stacked.
- Pads: current flat, lifted bevel, gradient face, bright bevel.
- Variations: composed Arp selector, Beat grid, Rhythm Gate tiles, Arp grid alternative, iOS wheel alternative, Rhythm vertical-list alternative.
- Toast: bottom-center pill, control-local pending indicator, placement alternatives.
- Progressions: chord-chip rail, mobile sheet, sidebar drawer, bar-notation ribbon, authoring-format reference.
