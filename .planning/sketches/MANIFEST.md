# Sketch Manifest

## Design Direction

Jay-6 visual redesign should feel like an instrument surface, not a generic web app: dark hardware chrome, warm cream pads, restrained orange only for currently sounding pads, and a muted steel system accent for queued/pending state. The redesign is an in-between visual adoption pass before milestone 2 sequencer work.

## Reference Points

- Roland J-6 physical control layout
- Pocket-operator / compact instrument chrome
- Existing Jay-6 v1 behavior and verified MIDI flow
- Claude design-canvas export imported from `.research/design/`
